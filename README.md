# german-daily-content

AktivDeutsch uygulamasının **"Günlük içerik"** sayfası için her gün güncellenen veri.

- `daily.json` — uygulamanın okuduğu dosya (şema: `TASK_PROMPT.md`).
- `TASK_PROMPT.md` — her sabah dosyayı güncelleyen planlanmış Claude görevinin talimatı.

Uygulama dosyayı şu adresten okur:
`https://raw.githubusercontent.com/<KULLANICI>/german-daily-content/main/daily.json`

Haberlerde yalnızca başlık, kendi cümlelerle yazılmış kısa özet ve orijinal kaynak bağlantısı bulunur.
